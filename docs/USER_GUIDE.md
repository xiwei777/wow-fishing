# 用户使用说明

1. 下载与你的系统和 CPU 架构匹配的发布包。Windows EXE 可以直接双击；Mac 解压后把 APP 拖入“应用程序”。不需要 Python、Conda、ChatGPT 或 Kimi。
2. 打开魔兽世界，使用窗口或无边框窗口模式，并保持游戏画面可见。Windows 暂不支持最小化/被遮挡时继续钓鱼，也不保证独占全屏截图。
3. 打开程序，等待“已就绪”。在 Mac 的隐私与安全性设置中为该 APP 授予屏幕录制、辅助功能，必要时授予输入监控权限并重启 APP。
4. 确认游戏动作条数字 `1` 是甩竿，数字 `5` 是上饵，切回游戏后按 F11。再按 F11 暂停，ESC 退出。
5. 切换到其他应用、最小化游戏或移动/缩放正在监测的窗口会暂停操作。返回游戏后再次按 F11 重新识别。
6. 点击“编辑配置”可修改按键和检测参数；保存后重启程序。配置保存在用户目录，不修改安装包。

## 保存位置

程序上的“打开保存目录”按钮可打开所有记录。

- Windows：`%LOCALAPPDATA%\WoWFishing`
- macOS：`~/Library/Application Support/WoWFishing`

每次会话在 `output/<时间_唯一编号>/` 中保存：

- `images/`：推理使用的原图。
- `annotated/`：带预测框和置信度的预览。
- `labels/*.txt`：归一化 YOLO 标签；未检测到鱼漂时为空。
- `labels/*.json`：时间、截图尺寸、预测框、置信度、模型 SHA-256 等。
- `session.json`：程序版本、模型指纹及检测参数。

自动预测不等于人工真值，空标签也不代表画面确实没有鱼漂。用于训练前需要人工检查。应用只记录模型标识，不额外导出权重。记录留在本机，不自动上传。截图会占用磁盘，可自行删除旧会话；关闭 `general.save_screenshots` 可停止保存新推理记录。

## 常见问题

- 启动失败：查看窗口日志和保存目录的 `logs/desktop.log`。
- 找不到窗口：检查游戏是否运行，以及配置中的 `window.owner_name` 和 `window.title_contains`。Windows 进程名可以填 `Wow`、`WowClassic` 等实际进程名。
- Windows 无法点击：检查游戏和工具的权限级别是否一致；优先都以普通用户运行。
- Windows 缩放：程序按客户区物理像素处理。100%、125%、150% 缩放与多显示器仍需目标电脑验收。
- Mac 权限：源码 Python 的授权不会自动转给 APP，第一次运行 APP 需要重新授权。
- 首次系统拦截：当前未配置发布签名/公证，系统可能提示未知开发者。正式面向更多用户发布时应配置 Windows 签名以及 Apple Developer ID 和公证；不要关闭系统安全机制。
